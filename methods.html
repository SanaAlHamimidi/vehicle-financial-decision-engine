Analytical Methods
Techniques, models, and feature engineering pipeline

🔄 Analysis Pipeline

01
Data Collection & Integration

Eight datasets were combined — Craigslist vehicle listings, six years of California DMV registration records by ZIP code and fuel type, and a vehicle MSRP reference dataset. Total data volume: 3.6 million registration records and 50,614 California vehicle listings.

02
Preprocessing & Cleaning

Outlier removal (price $500–$150,000, odometer 1,000–300,000 miles, year ≥ 2000), null handling, duplicate removal, and column standardization across datasets with inconsistent naming conventions.

03
Geographic Feature Engineering — Demand Score

ZIP codes in the registration dataset were mapped to California regions using pgeocode reverse geocoding and a manual county-to-region mapping. Registrations were then aggregated by region, make, and fuel type across all six years and normalized to a 0–1 demand score.

04
Depreciation Rate Calculation

Average MSRP was calculated per make and year from the reference dataset. For makes not present in the MSRP dataset, proxy brands were assigned based on market segment similarity. Depreciation rate was computed as (avg_msrp − current_price) / avg_msrp.

05
Modeling & Evaluation

XGBoost regressor trained on 80% of 37,991 cleaned listings and evaluated on the remaining 20%. K-Means clustering applied to discover natural depreciation profiles. Feature importance extracted to validate findings.

06
Deployment

Flask API containerized with Docker and deployed to Google Cloud Run. Website hosted on Google App Engine. Model artifacts and lookup tables stored in Google Cloud Storage.

🤖 Machine Learning Methods

XGBoost Regressor — Price Prediction

Gradient boosting ensemble method that builds decision trees sequentially, each correcting errors of the previous. Selected for its strong performance on tabular data with mixed feature types, robustness to outliers, and interpretable feature importance scores.

Input: year, odometer, manufacturer, condition, fuel, type, region, demand_score
Output: predicted resale price ($)
n_estimators: 100 max_depth: 6 learning_rate: 0.1 subsample: 0.8 colsample_bytree: 0.8

K-Means Clustering — Depreciation Profiles

Unsupervised clustering applied to avg_msrp, depreciation_rate, odometer, and year to discover natural vehicle depreciation tiers. Features were standardized using StandardScaler before clustering to ensure equal contribution. Optimal K=5 selected using the elbow method.

Input: avg_msrp, depreciation_rate, odometer, year
Output: cluster label (1–5 depreciation tier)
K = 5 clusters Euclidean distance StandardScaler n_init = 10

Demand Score — Feature Engineering

Geographic demand was not directly measurable from listing data alone. A proxy demand signal was engineered from six years of California DMV registration records by aggregating vehicle counts per region, make, and fuel type, then normalizing to a 0–1 scale.

Input: region + make + fuel type from registration data
Output: demand_score ∈ [0, 1]
6 years of data 29 CA regions pgeocode ZIP mapping

⚠️ Methodological Limitations

Data Limitations

  • Craigslist listings represent private sellers only — dealer and auction markets excluded
  • Brand-level MSRP averaging may inflate depreciation for economy brands proxied to more expensive makes
  • MSRP dataset covers 13 brands — 26 brands use proxy values from similar market segments
  • ZIP-to-region mapping uses county-level approximation

Model Limitations

  • R² of 0.779 — 22% of price variation remains unexplained
  • Model struggles with high-priced vehicles above $50,000 due to fewer training examples
  • Label encoding introduces implicit ordinal relationships in categorical features
  • No temporal tracking — model reflects a single market snapshot
