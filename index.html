Vehicle Financial Decision Engine

A data-driven project that helps people make smarter vehicle decisions by studying depreciation, regional market behavior, and long-term financial value.

Group ID: 20
Members: Nyi Wai Yan Tun, Sana Al Hamimidi

Project Summary

This project helps car buyers make smarter financial decisions by looking beyond the listed price of a vehicle. The platform focuses on long-term financial effects like depreciation, insurance-related cost context, and region-based market behavior across California.

A major idea behind this project is that vehicle value does not change the same way everywhere. A truck may hold value better in one region while losing value faster in another. Because of that, the website is designed to let users compare depreciation patterns across regions and understand how geography affects the long-term value of a car.

The system is also planned to use machine learning to assign each vehicle a depreciation rating out of 5, helping users compare vehicles in a way that is easier to understand.

Data Sources

  1. vehicles.csv - Craigslist vehicle listings used for California resale analysis.
  2. vehicle fuel-type registration datasets - annual registration data by zip code and fuel type in California.
  3. car_data.csv - vehicle MSRP and pricing data used to help estimate depreciation behavior.
  4. Insurance expenditure data - state-level cost context for ownership.

Core Features Used

  • Region and zip-code based demand
  • Price, year, and odometer
  • Manufacturer, model, condition, fuel, type, and size
  • Registration trends and geographic market differences

Preliminary Findings

  • Newer vehicles tend to list for higher prices.
  • Higher mileage is linked to lower prices.
  • Top registered brands also appear among the most listed used cars in California.
  • Regional demand likely plays a meaningful role in resale value.
  • Fuel type alone is not enough; vehicle type also matters when studying depreciation.

Questions the Project Tries to Answer

  • How does geography within California affect depreciation?
  • Which vehicle features most influence resale value over time?
  • What combination of price, interest rate, demand, and location gives the best long-term value?
  • Which vehicle segments keep a more stable depreciation curve across regions?

Broader Impacts

This project can help first-time buyers, students, seniors, and budget-conscious families understand the hidden long-term cost of owning a car. It can also help gig drivers and small dealerships make smarter decisions using clearer market signals.

By turning complicated financial patterns into simple visual comparisons, the platform supports better planning, better negotiation, and better value for buyers over time.
