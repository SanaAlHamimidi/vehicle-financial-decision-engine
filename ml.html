Machine Learning

ML Models

The machine learning approaches powering the depreciation rating system — from regression models to ensemble methods trained on California vehicle data.

Models

What we built & tested

Model 01

Linear Regression Baseline

Predicts resale price from mileage, age, make, and region. Establishes a performance baseline for more complex models.

Model 02

Random Forest Regressor

Captures non-linear relationships between vehicle features. Provides feature importance rankings to identify top depreciation drivers.

Model 03

Gradient Boosting (XGBoost)

High-accuracy ensemble model for final depreciation predictions. Weighted by reliability scores and demand index.

Evaluation

How we measured performance

Metric

RMSE

Root Mean Squared Error — measures how far off predicted resale prices are from actual values in the test set.

Metric

R² Score

Proportion of variance in resale price explained by the model. Target: R² > 0.80 for production use.

Metric

Cross-Validation

5-fold CV to ensure models generalize across different California regions and vehicle segments.
